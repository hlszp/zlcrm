# PVD 工厂经营系统

面向等离子电镀（PVD）企业的客户、合同、财务、生产和经营分析系统。后端使用 Flask + SQLite，前端使用原生 JavaScript，老板移动端使用可安装的移动 Web/PWA，与桌面端共用认证、权限和统计接口。

线上地址：https://crm.zlinfot.com
老板移动端：https://crm.zlinfot.com/mobile

## 已完成的工作

### 1. 安全与业务止损

- 按 admin、finance、manager、sales 实施后端角色权限和合同归属校验。
- 生产环境强制配置 `CRM_SECRET`，新数据库必须通过 `CRM_ADMIN_PASSWORD` 创建管理员，不在日志中输出密码。
- 防止跨合同期次收款、超收、超开、重复发票、超合同发货和非法数量。
- 临时发货使用单事务，失败不残留合同；单号使用数据库计数器，删除后不重号。
- 正式、演示、全部数据使用会话级隔离，覆盖列表、详情、看板、提醒和导出。
- 附件目录跟随 `CRM_DB`，也支持 `CRM_UPLOAD_DIR`；SVG 强制下载，响应带 CSP 沙箱，Excel 自由文本防公式注入。

### 2. 合同财务与对账

- `finance.py` 统一计算合同额、计划额、实收、有效开票、未收、未开票、未排期和待核销。
- 合同变更保留前后快照、金额、原因、操作者和时间。
- 收款支持一次或多次部分核销、跨期次核销及取消核销，原始收款不被核销操作覆盖。
- 发票支持部分或全部红冲，统计使用红冲后的净额。
- 合同改价不能低于已收、有效开票或计划总额；明细改价也执行同一约束。
- 已有财务、生产或变更记录的合同不能硬删除；关键写操作进入 `audit_logs`。
- 账龄按未排期、未到期、1–30、31–60、61–90、90 天以上分类；归档合同使用一致口径。

### 3. PVD 行业生产闭环

- 来料批次：工件、图号版本、材质、数量、表面状态和合同客户。
- 炉次：工艺、配方、设备、操作人、装炉量、开始和结束时间。
- 质检：检验量、合格/不合格量、结合力、膜厚、盐雾、让步接收和报告信息。
- 发货可关联来料批次；签收和验收支持部分数量及累计上限。
- 验收状态按累计数量回写批次；对账支持待确认、已确认和异议，防止有效期间重叠。
- “生产协同”页面覆盖来料、炉次、质检、签收验收、对账、成本和设备。

### 4. 经营分析

- 成本按合同及可选批次/炉次归集，覆盖靶材气体、电费、人工、前处理、挂具摊销、检测、运输、外协、返工和赔偿。
- 展示合同额、当月成本、预估毛利、毛利率、成本类别和亏损合同，并支持 Excel 导出。
- 设备维护每日可用工时，按真实炉次计算实际工时、平均工时和产能利用率。
- 一次合格率只使用每炉第一次质检；无数据时返回空值而不是伪造 0%。
- 客户风险结合未收、逾期、信用额度、停接标记和合同集中度，展示触发原因。
- 老板移动端提供经营 KPI、逾期、欠款、交付、客户风险、质量和毛利信息。

### 5. 部署与数据修复

- 已在真实服务器完成代码上传、数据库迁移、服务重启和公网验收。
- 线上服务为 systemd + Gunicorn，健康检查与移动入口可用。
- 已轮换线上 Flask 会话密钥，默认管理员密码已失效。
- 部署前备份包含旧代码、当前数据库和附件。
- 审查发现旧核销迁移会在启动时重复回填；已修复幂等性并精确清理重复记录。连续启动不会增加核销金额。

## 本地运行

### 准备环境

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

### 首次初始化

首次创建数据库时必须提供管理员密码。不要把真实密码写入源码或提交到 Git。

```bash
export CRM_ADMIN_PASSWORD='replace-with-a-strong-password'
python app.py
```

默认监听 `127.0.0.1:5000`，可用 `PORT` 修改端口。

### 生产配置

```bash
export CRM_ENV=production
export CRM_SECRET='replace-with-a-long-random-secret'
export CRM_ADMIN_PASSWORD='replace-with-a-strong-password'
export PORT=9000
gunicorn -w 2 -b 0.0.0.0:9000 app:app
```

生产环境缺少 `CRM_SECRET` 时会拒绝启动。已有数据库不需要再次设置初始管理员密码。

## 数据与备份

- 默认数据库：`data/crm.db`，可用 `CRM_DB` 指定其他路径。
- 默认附件：数据库同目录下的 `uploads/`，可用 `CRM_UPLOAD_DIR` 单独指定。
- 默认只显示正式数据；管理员可在当前会话切换演示或全部数据。
- 执行备份：

```bash
bash backup.sh
```

- 备份目录：`backups/日期时间/`；脚本保留最近 30 天。
- `data/`、`backups/`、附件、`.env` 和缓存均被 `.gitignore` 排除。
- 不要在生产库直接运行演示灌入或清理脚本；生产环境需要显式 `--force`，但仍应先确认目标库并备份。

## 当前边界

- 未做异地容灾；服务器本地备份不能替代异地副本。
- 登录接口尚未增加速率限制。
- 管理员删除原始收款/发票仅作为保留审计快照的例外操作。
- 毛利为“合同额减已归集成本”的经营预估值，不是法定财务利润。
