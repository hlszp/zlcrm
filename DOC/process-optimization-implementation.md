# 工艺寻优模块实施与验收记录

## 交付范围

本模块按“配方版本 → 批次执行 → 人工实测 → 质量结果 → 异常复盘 → 改进验证 → 新版本发布”实施，复用现有合同、来料、炉次、质检、成本、权限和演示隔离体系。

### 配方与版本

- 配方维护工艺、材料、工件类别、设备适用范围和参数集合。
- 参数包含编码、名称、工序、单位、类型、标准值、上下限和必填约束。
- 新增 `engineer` 工艺工程师角色；工程师维护草稿，管理员审核发布。
- 发布版不可修改；发布新版本时旧发布版本自动停用。
- 执行批次保存完整版本快照，后续版本变更不改写历史。

### 批次执行与过程监控

- 从现有炉次创建工艺执行批次，校验合同权限、当前发布版本和演示归属。
- 每个炉次只允许一个未作废工艺记录，单号由数据库计数器生成。
- 实测值区分正常、异常、缺失和估读；空值不作为 0，数值超上下限自动标异常。
- 必填参数缺失时不能提交；支持草稿、待审核、已审核和已作废。
- 已审核记录只能由工程师或管理员修订，经理不能修改；所有修订写入审计日志。
- 工艺事件支持工序开始/结束、参数调整、停机、返工、异常处理和其他。
- 附件支持 PDF、图片、文本、CSV 和 Excel；随机存储名、合同权限和 CSP 沙箱由后端执行，SVG/HTML 不允许上传。
- 监控展示异常参数、缺失参数、待审核和超过 24 小时未更新记录。它只反映人工记录，不代表设备实时状态。

### 对比分析与改进专题

- 按配方和版本汇总批次、质量合格率、异常、炉次成本和周期。
- 参数提供趋势、有效样本数、均值、极值、总体标准差、异常/缺失/估读数量。
- 少于 3 个有效数值时明确提示“仅作描述”；所有统计均为描述性结果，不生成虚假寻优结论。
- 标杆候选必须已审核、无异常/缺失且质量合格率为 100%，并可继续追溯成本与周期。
- 双批次对比展示参数差值、质量百分点变化、成本变化和周期变化。
- 改进专题记录问题、假设、变量、基准批次、候选批次、结论和形成版本。
- 已结案或已取消专题不可直接修改；创建、更新和结案进入审计日志。
- 老板移动端增加工艺异常、待审核、久未更新、改进数量和最近结案效果。

## 数据表

- `process_recipes`
- `process_recipe_versions`
- `process_parameter_defs`
- `process_runs`
- `process_run_values`
- `process_events`
- `process_attachments`
- `process_improvements`

主要接口统一位于 `/api/process/*`。分析使用批次关联的质检与成本记录；无质检或无成本时返回空值，不伪造为 0。

## 本地验证记录

使用临时 SQLite 数据库和真实 Flask API，不运行生产演示灌入或清理脚本。

- 配方创建、提交、发布、旧版停用、发布版不可改和角色拒绝。
- 炉次执行批次创建、版本快照、重复记录拒绝和正式/演示串数据拒绝。
- 必填缺失、超限异常、提交、审核、审核后修订权限与审计。
- 工艺事件、附件上传与读取、SVG 拒绝、24 小时未更新预警。
- 双批次参数/质量/成本/周期对比、参数统计、异常排序、标杆候选。
- 改进专题部分更新保留变量、结案约束、结案后不可改及移动端效果摘要。
- 在 iPhone 14 Pro 尺寸的隔离浏览器环境中验证登录、移动端 KPI 和工艺摘要。
- 在桌面浏览器中验证五个页面、已审核参数修订回读及双批次对比弹窗。

## 上线与运维边界

- 新版本部署前必须备份数据库和附件；只上传代码，不上传本地数据库。
- 启动时 `CREATE TABLE IF NOT EXISTS` 创建新增表，`migrate_v11` 保留既有用户并增加工程师角色。
- 本模块不包含设备联网、实时控制、自动参数推荐或人工智能寻优。
- 统计结论必须回到批次、版本、实测值、质检和成本证据，由工艺人员作最终判断。
