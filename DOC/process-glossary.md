# 工艺模块术语

- **工艺配方（Recipe）**：在明确工艺、材料、工件和设备适用范围下的一组工序与参数规则。
- **配方版本（Recipe Version）**：配方在某一时间的完整、可审核快照；发布后不可直接修改。
- **执行批次（Process Run）**：某个炉次实际使用某配方版本所形成的工艺记录。
- **参数实测值**：执行批次中由人工记录的目标值、上下限、实际值、单位和异常状态。
- **工艺事件**：执行过程中的开始、结束、调整、停机、返工或其他可追溯事件。
- **标杆批次**：在明确适用范围内，质量稳定且综合表现较好的参考执行批次，不代表通用最佳实践。
- **改进专题**：围绕明确问题形成的假设、对照、试验、结论和版本发布闭环。
- **过程监控**：基于人工记录形成的进度、偏差、异常和时效性监控，不等于设备实时采集。
